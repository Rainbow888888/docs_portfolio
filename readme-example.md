# CSV to JSON Converter

Превращает CSV-файлы в JSON одной командой.

## Возможности

- Работает с файлами любого размера
- Сохраняет заголовки столбцов как ключи JSON
- Поддерживает русские символы (UTF-8)
- Можно указать свой разделитель (запятая, точка с запятой, табуляция)

## Требования

- Python 3.8 или новее
- Библиотеки: csv (встроенная), json (встроенная)
