# Как запустить простой веб-сервер на Python за 5 минут

**Зачем это нужно:** Показать коллеге HTML-страницу или проверить сайт на телефоне без настройки Apache.

**Что понадобится:**
- Компьютер с Windows, macOS или Linux
- Установленный Python (проверьте командой `python --version`)

---

## Шаг 1. Откройте терминал

- **Windows:** нажмите `Win + R`, введите `cmd`, нажмите Enter
- **macOS:** откройте «Программы» → «Утилиты» → «Терминал»
- **Linux:** нажмите `Ctrl + Alt + T`

## Шаг 2. Перейдите в папку с вашим сайтом

`bash
cd /путь/к/папке/с/html
`
## Шаг 3. Запустите сервер

`python -m http.server 8000`

**Что вы увидите:**
`Serving HTTP on 0.0.0.0 port 8000 ...`
